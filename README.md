# LoL Skin GLB Viewer

Static browser viewer for GLB models exported by the local LoL Custom Skin Viewer.

Select a local GLB file to rotate, zoom, and play its animations. Model data is processed in the browser and is not uploaded. The model-viewer library is loaded from Google CDN.

This repository contains viewer code only, with no game assets or mods. GitHub Pages can publish the main branch root directory.
